# 🧵 UV Capitals Backend (Node.js + PostgreSQL)

**Unified Vision Capital is an Investment Banking firm based in Noida. We work with companies to raise funds, manage/advise transactions, and connect them with the right investors.**

This is the backend API for **UV Capitals**, a modern finance company platform. Built with **Node.js**, **Express**, and **PostgreSQL**, this backend powers both customer-facing and admin-side workflows.

---

## 🚀 Features

- ✅ RESTful API built with Express.js  
- 🗃️ PostgreSQL database with custom datasets management  
- 🔐 JWT-based authentication with role-based access control  
- 🛒 Product catalog and order management system  
- 📁 File uploads using Multer  
- 📧 Email notifications powered by Nodemailer

---

## 🏗️ Tech Stack

- **Backend:** Node.js, Express.js  
- **Database:** PostgreSQL  
- **ORM/DB Layer:** Custom Datasets Management  
- **Authentication:** JWT, bcrypt  
- **File Uploads:** Multer  
- **Email Service:** Nodemailer  
- **Configuration:** dotenv
